## Full description

```
Induction Program Past Papers helps newly recruited government teachers in
Khyber Pakhtunkhwa prepare for the Teacher Induction Program examinations.

COVERAGE
• Phase II, Phase III, and Phase IV
• All 8 subjects: English, Mathematics, General Science, Islamiat / Nazra
  Quran, Use of ICT in Education, Classroom Management and Assessment,
  Educational Psychology, and Curriculum and Instruction

WHAT'S INSIDE EACH PAPER
• Original paper viewer (exactly as supplied, with zoom and page navigation)
• MCQ answer key with explanations
• Solved short questions
• Solved long questions
• Complete solved paper, with search, bookmark, and share

STUDY TOOLS
• Practice MCQs by phase and subject, with instant scoring
• Bookmark any question or paper for later review
• Track your progress and accuracy by phase and subject
• Global search across all published content
• Works with cached content when your connection is slow

QUALITY YOU CAN TRUST
Every question is independently quality-checked. Where a printed answer
key doesn't match the academically correct answer, both are shown clearly
so you always know what to trust.

Induction Program Past Papers is an independent educational preparation
resource. It is not an official government application unless explicitly
stated otherwise.
```

## Data Safety declaration (matches actual app behavior)

Collected: name, email address, phone number, and other user-provided
information (district) for account creation; app activity (practice
attempts, bookmarks, progress) to provide app functionality. Data is
encrypted in transit. Users can request account and data deletion in-app
(Profile → Delete Account). No data is sold. No advertising or analytics
SDKs are integrated in this release — update this section immediately if
that changes.
